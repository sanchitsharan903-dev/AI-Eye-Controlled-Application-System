"AI Eye Controlled Application System"

1.Overview
An AI-powered computer vision application that enables users to control desktop and mobile applications using only eye movements.


2.Features
- Face Mesh Detection
- Iris Tracking
- Eye Gaze Detection (In Progress)
- Mouse Cursor Control (Upcoming)
- Blink Detection (Upcoming)
- Double Blink Click (Upcoming)
- Scroll using Eye Movement (Upcoming)
- Virtual Keyboard (Upcoming)
- Android Mobile Control (Upcoming)


3.Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy
